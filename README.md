Magic Event Manager Web (React + Vite)

- Stack: React + TypeScript + Vite + Tailwind CSS
- Dev port: 5173 (Vite)
- Docker serve: nginx on :80
- Env: `VITE_API_BASE_URL` (defaults to `/api`)

Key Routes
- `/` events list
- `/events/new` create event
- `/campaigns` campaign templates list
- `/campaigns/new` template builder + live preview

Run
- `npm run dev` – dev server
- `npm run build` – production build
- `npm run preview` – preview build
